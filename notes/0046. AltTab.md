## 2. 评价

这个 macOS 工具蛮好用的，从 `25.05` 开始体验，目前 `26.01` 还在用。

## 3. AltTab 是什么？

AltTab 是 macOS 上的一款用于切换应用页面窗口的开源工具，它可以让你向在 Windows 中那样，直接通过 `Alt Tab` 来快速切换不同的应用窗口，并且支持配置。

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-05-24-23-17-18.png)

基于 macOS 原生框架开发（主要语言为 Swift）。

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs-2026@main/2026-01-01-20-44-11.png)
