- DeskPins 简介

## 2. 评价

这篇笔记介绍了一款 Windows 中用于将窗口置顶的工具 DeskPins，目前（26.01）仍在使用，这玩意儿很轻量，使用起来也非常简单。

## 3. DeskPins 是什么？

DeskPins 是在 `windows` 系统中用于解决 `窗口置顶` 工具。

特点：

- `免费`
- `便捷` - 支持自定义快捷方式
- `轻量` - 体积小，安装后总共就 3 个文件，加起来也不到 `200KB`
  - ![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-05-05-07-12-21.png)

## 4. DeskPins 如何使用？

### 4.1. 下载并安装 DeskPins

- 方式 1：安装包可以自行到 DeskPins 的官网下载。（推荐）
- 方式 2：在 TNotes.yuque 上也有记录 DeskPins 的安装包，有需要的也可自行下载安装。

![2](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-05-05-07-20-29.png)

:::

### 4.2. 打开 DeskPins

个人常用的快捷方式：按下 `Win` 键，输入 `desk……`，找到应用后直接回车即可！

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-05-05-07-13-25.png)

### 4.3. 窗口置顶

先点击 DeskPins 图标，再点击需要置顶的窗口。

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-05-05-07-14-11.png)

比如将浏览器窗口置顶：

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-05-05-07-14-22.png)

成功置顶后，窗口右上角会多出一个图钉 📌 的 logo。

### 4.4. 取消窗口置顶

取消哪个窗口，就再点一次那个窗口上右上角的图钉 📌 即可。

## 5. DeskPins 都有哪些常用的快捷键？

- `Ctrl F11` - 选择一个窗口置顶
- `Ctrl F12` - 快速切换当前窗口的置顶状态：
  - 若当前窗口 - 未置顶，按下 `Ctrl F12` 之后会 将当前窗口置顶
  - 若当前窗口 - 已置顶，按下 `Ctrl F12` 之后会 将当前窗口取消置顶

### 7.1. 维基百科 - patras greece

https://en.wikipedia.org/wiki/Patras

从英文翻译而来-帕特雷是希腊第三大城市，也是希腊西部地区首府和最大城市，位于伯罗奔尼撒半岛北部，距雅典以西 215 公里。

这座城市建在帕纳柴孔山脚下，俯瞰帕特雷湾。

截至 2021 年人口普查，帕特雷市人口为 215,922 人，而城市人口为 173,600 人。

核心聚落已有四千年的历史。
