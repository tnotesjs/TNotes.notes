## 2. 评价

暂时不清楚如何分组的笔记，都统一丢到这个仓库中。以免想写东西的时候，因过分纠结不知道应该把写的内容丢到哪个知识库中而放弃写笔记，因小失大。

目前在 `TNotes.notes` 知识库记录的内容包括：

- 分享一些个人的 PC 使用技巧，比如一些常用软件（比如 Snipaste、Wgesture）的使用技巧分享等
